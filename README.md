# Animarium

**Synthetic populations of Italian cities, in the browser.**

Animarium is a static viewer for the synthetic populations generated by
[GSP](https://github.com/mirko-degli-esposti/gsp): choose a municipality,
filter on any attribute by clicking a bar, compare the filtered marginals
with the whole city and with the census, read the institutional-trust
battery with honest confidence bands, place individuals on a map, open the
card of a single (non-existent) person. The whole state lives in the URL, so
a view can be sent in one line and cited in a paper.

Live: <https://animarium.it>. Eleven municipalities — the nine
provincial capitals of Emilia-Romagna, Brescia and Castenaso — about 1.9 M
individuals, 0.9 M households, bundle ≈ 37 MB.

Animarium **consumes** populations, it does not generate them. GSP produces
`popolazione_K*C_avq_full.csv`; Animarium turns it into a Parquet bundle and
serves it. The two are documented together in the technical report
*Animarium: an open, reproducible pipeline for synthetic populations of
Italian cities* (arXiv, v1.0, identifier added on release); design decisions,
measurements and retractions are in `note/design_animarium_vNN.md`.

**Nothing shown here describes a real person.** Every card says so. What is
and is not real in a record, and why the residual risk is one of
interpretation, is argued in GSP's `note/piano_trattamento` and in the
report, Part I.7.

## Two ways in

**A. You have the bundle** (downloaded from the Zenodo dataset, or built by
someone else). No Python dependency on GSP is needed.

```bash
git clone https://github.com/mirko-degli-esposti/animarium && cd animarium
# put the bundle in ./bundle/  (bundle/comuni.json + bundle/comuni/<codice>/…)
python build/serve_range.py
# open http://localhost:8000/build/pannello_marginali.html
```

`serve_range.py` is a static server with HTTP Range support; `python -m
http.server` does not support Range and would break both the viewer and any
byte-count measurement.

**B. You have GSP installed and populations generated.** The build scripts
import `gsp.common` for the municipality registry, zone names, AVQ set and
project root — nothing is duplicated here.

```bash
pip install -e <clone of gsp>          # or: pip install -e ~/progetti/gsp
export GSP_ROOT=<clone of gsp>         # only if it is not ~/progetti/gsp
python build/build_bundle.py           # all municipalities in the registry
python build/build_bundle.py 034027    # one
```

`build_bundle.py` runs, per municipality, `to_parquet.py → manifest_min.py →
build_riferimenti.py`, then `build_indice.py` once; it skips what is up to
date, reports the resolved constraint level, and does not stop at the first
failure. The scripts remain usable one by one.

The **public regime** is applied in `to_parquet.py` through
`gsp.individui.esporta_pubblico`, the single point where regimes are
enforced: no name, no street or civic number, coordinates randomised within
the census section, `donor_id` dropped. What leaves the machine is what you
see online.

**Publishing** — one command, which assembles `deploy/` from the bundle on
disk and hands it to Wrangler, so that assembly and upload cannot drift
apart:

```bash
python build/deploy.py --cloudflare
```

(`--gh-pages` publishes to a throwaway branch instead: an earlier
configuration, kept as a fallback.)

## Layout

```
build/                  Python (bundle chain, deploy, range server) + the viewer page
  pannello_marginali.html   the viewer: one file, hand-written, DuckDB-WASM from CDN
  smoke_duckdb.html    byte-cost smoke test (published as smoke.html: checks the host answers Range requests)
bundle/                 generated, not versioned, rebuilt in one command
deploy/                 generated, not versioned, what goes online
note/                   design document (versioned), measurements, retractions
```

Pipeline diagnostics (`verifica_vincoli`, `verifica_donor`, `diag_*`,
`ispeziona_*`) used to live in `build/`; they belong to the pipeline and moved
to `gsp/scripts/diagnostica/`.

## The panel

**Filters** are the bars themselves; active filters become removable pills;
state is entirely in the URL.

**Three markers**, three meanings:

| | what it is | the gap measures |
|---|---|---|
| **bar** | the filtered subpopulation | — |
| **tick** | the whole city | the **association** between filter and attribute |
| **diamond** | the census, at the filter's level | the **model error** |

The diamond appears only where a block of the constraint set contains both
the filter's attributes and the displayed one; the panel says where it does
not, instead of hiding it.

**Institutional trust** (lazy: block B is read on request): the battery on a
0–10 axis, ordered by mean, with **two overlaid bands** — thin on `n`, thick
on Kish `n_eff` computed per variable universe. The distance between the two
is why `n_eff` exists. Dotted ticks mark national means where known
(a GSP-registered derived source). AVQ variables carry **no geographic
information** by construction (GSP assumption 6): filtering a zone, any
difference is compositional, and the panel says so.

**Map** (lazy: block C on request): share of the filter per ~150 m cell, or
sampled individuals with deterministic jitter over a grey layer of the whole
city; individuals are clickable and open the card, with the guarantee class of
every attribute. Coordinates are those of the public regime.
The cartographic base layer is off by default — the panel draws its own geometry. Switching on OpenStreetMap is an explicit choice, labelled as an external service and attributed on the canvas; CARTO support exists in the code but is currently disabled, since it now requires an API key.A self-hosted PMTiles layer is planned for v1.1.

**Households** (ring 4): family nuclei with role, from the bundle.

**Export**: CSV and LaTeX (`booktabs`) of marginals and trust, SVG per panel.

## Cost model

DuckDB-WASM reads **contiguous byte ranges, not columns**: three columns or
five of the same block cost the same. Columns are therefore laid out in three
blocks by use (filters / AVQ / map), rows sorted by `zona, sezione`, row
groups of 20 000, so that

    cost(query) = footer + Σ weight(block) × (row groups not pruned / total)

Later filters inside a block cost zero bytes. Measurements per municipality
are in the design note.

---

## Working rule

No number enters the design without its comparison. Every error found so far
came from comparing against a configuration with a known answer: raw MAE
against normalised, distinct-count against Kish, relative error against
z-score, `n_eff` on the right universe against the wrong one. Results that
were withdrawn are annotated as such in the design note, not removed.
